# Tenge 2.1

Tenge is a personal finance management web application built with Flask, HTML, CSS, JavaScript, and SQLite.

## Features

- User registration and login
- Balance management
- Income and expense tracking
- Bank card management
- Transaction history

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install -r requirements.txt
python app.py
